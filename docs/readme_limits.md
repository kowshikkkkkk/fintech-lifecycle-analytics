# Limits (draft)
- L1: Data are page views, not completed actions; registration and transfer/withdrawal completion are not observable.
- L2: Failure causes for deposits cannot be separated (no error code).
- L3: A single person may appear as several IDs (e.g., email link opened on another device), so user counts can be inflated and sequences broken.
- L4: Dates were modified by the publisher; day-of-week and time-of-day are not used.
- L5: Heavy users (top 0.1%, 338 users, 12.0% of events) may include power users, shared IDs or automation; they are flagged, kept, and results are reported with and without them.
